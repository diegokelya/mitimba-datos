# mitimba-datos

Resultados que descarga la app MiTimba: quiniela (`real/results.json`) y juegos poceados (`games/results.json`).

Se actualizan automáticamente varias veces por día a partir de las publicaciones oficiales de LOTBA, Lotería de Santa Fe y Telekino. Cada registro guarda la dirección de origen y la fecha de consulta. El repositorio conserva un único commit que se reemplaza en cada actualización.

Solo información. Contrastá siempre los resultados con el extracto oficial.
